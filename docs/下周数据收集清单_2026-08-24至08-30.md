## 二、三类XLSX需要保留的字段

### 1. 收货表

收货表示货物已经到仓，但不等于已经进入正式库存区。

|必要字段|说明|
|---|---|
|收货日期|实际完成收货的日期|
|收货单号或批次号|用于去重和追溯|
|品类|必须能够识别“鞋”|
|实收数量|保留原表数量|
|数量单位|双、件、箱或托|
|整托/散货标识|如原表存在则保留|
|异常数量|短少、破损或拒收，如原表存在则保留|

### 2. 上架表

上架表示货物正式进入整托区或散货区，是库存增加的主要依据。

|必要字段|说明|
|---|---|
|上架日期|实际完成上架的日期|
|上架单号或任务号|用于去重和追溯|
|品类|必须能够识别“鞋”|
|上架数量|实际完成数量|
|数量单位|双、件、箱或托|
|目标区域|整托区或散货区|
|关联收货批次|如原表存在则保留|

### 3. 发货表

|必要字段|说明|
|---|---|
|发货日期|实际完成发货的日期|
|订单号、发货单号或波次号|用于去重和追溯|
|品类|必须能够识别“鞋”|
|发货数量|实际完成数量|
|数量单位|双、件、箱或托|
|来源区域|整托区或散货区|
|业务类型|主单、补单、2C，如原表存在则保留|

## 五、需要确认的业务口径

### 库存计算

```text
暂存区变化 = 当日收货量 − 当日上架量

正式库存变化 = 当日上架量 − 当日发货量 + 库存调整量
```

请确认：

- [ ] WMS在收货完成还是上架完成后增加正式库存；
- [ ] 退货重新上架记录在哪张表；
- [ ] 报废和盘亏是否会生成独立调整记录；
- [ ] 整托转散货是否同时生成一减一增记录；
- [ ] 月末关账库存是否包含暂存区待上架货物；
- [ ] 收货、上架和发货数量能否统一换算为“双”。

### 单位换算

当前鞋类换算基准：

```text
1箱 = 9双
1托 = 16箱 = 144双
1个散货库位 = 9双
```

- [ ] 确认上述换算是否适用于全部7—8月鞋类数据；
- [ ] 如存在不同箱规或托规，提供对应编码和换算规则。

## 六、数据质量验收

收到文件后按以下标准验收：

- [ ] 文件可以正常打开且未加密；
- [ ] 原始文件未经删除列、改表头或手工汇总；
- [ ] 日期覆盖范围连续；
- [ ] 鞋类可以从其他品类中稳定筛选；
- [ ] 数量单位可以识别和换算；
- [ ] 整托、散货区域可以识别；
- [ ] 同一业务单据可以通过唯一编号去重；
- [ ] 每日汇总与月度总量基本一致；
- [ ] 理论库存能够与关账库存进行闭环校验；
- [ ] 差异能够归因至盘点、退货、报废、冲销或区域转换。

库存闭环校验公式：

```text
理论期末库存 = 期初库存 + 累计上架 − 累计发货 + 累计调整
```
