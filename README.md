# 青浦仓智能决策看板

面向客户与管理者的仓储认知和状态模拟 Demo。项目把专业仓储数据转化为更直观的界面，帮助不熟悉仓储业务的人快速回答两个问题：

1. 当前仓库处于什么状态？
2. 按设想的入库量和出库量运行后，未来某个时点可能处于什么状态？

## 当前模块

- **项目首页**：说明项目价值、产品边界和演进路线。
- **7月鞋类日级看板**：将31天入库、出库和库存快照映射为可播放的仓库状态线，支持按日期回看、库存水位判断和关键转折定位。
- **仓库全流程**：展示收货、上架、盘点、发货、退货和系统支撑六个运营域。
- **鞋品状态模拟器**：以2026年7月31日真实库存快照为起点，输入累计入库量、出库量和目标日期，通过仓储货架容量视图、7月业务强度标尺和压力时间线呈现未来状态及 A—D 风险等级。
- **现场洞察**：收货与盘点场景的结构化观察报告。

## 数据与产品边界

当前版本基于青浦仓 2026 年 7 月人工收集的鞋类日级入库、出库和库存数据，用于验证产品界面、日期回看、情景输入和评级逻辑，并非实时 WMS 事实看板，也不代表正式履约承诺。

模拟器采用简化关系：

```text
未来库存 = 7月31日实际库存快照 + 预计入库 − 预计出库
```

进出库量按照 7 月历史比例分配到整托区和散货区。只有接入 WMS 并持续获得完整、统一口径的数据后，项目才能形成更真实有效的事实看板；当数据能够按日更新时，可进一步评估突发大批量入库对仓库造成的实际压力。

当前压力区间暂按 70% 观察起点、85% 高压提示线和 100% 容量上限划分。70% 与 85% 为产品 Demo 规则，并非仓库正式 SOP；日级看板同时显示所选日期在 7 月库存分布中的历史位置，避免把“月内高位”误读为“接近满仓”。

## 本地预览

本项目为静态站点，可在项目目录运行：

```bash
python3 -m http.server 4173
```

然后访问 `http://localhost:4173/`。
